Notes on the mapping, so it's not a black box:
- Text tiers: `#F5F5F5`→primary text `oklch(97%_0.005_265)`, `#A3A3A3`→secondary `oklch(85%_0.005_265)`, `#666666`→muted `oklch(55%_0.01_265)` — matching the tiers already used across `frontend/src/app/app/page.tsx` and every other V2 view.
- Surfaces: `#111111`→card `oklch(13%_0.015_265)`, `#1A1A1A`→elevated/hover `oklch(15%_0.015_265)`, `#1F1F1F`→input `oklch(17%_0.015_265)`, `#2A2A2A`→border `oklch(22%_0.015_265)` — the exact, most-frequent tokens for each role across the existing V2 codebase (verified by frequency count).
- Accent: `#1E90FF`/`#3BA0FF` (old app's blue accent + hover) → V2's own established warm accent `oklch(85%_0.16_84)` / `oklch(82.8%_0.189_84.429)` — V2 uses a gold/amber highlight, not blue, for its primary actions (e.g. the Chat page's send button); this is a deliberate visual-language change, not a literal hue conversion, per the design spec's "restyled with V2's oklch visual language" requirement.
- Severity: `#4ADE80`→`oklch(79.2%_0.209_151.711)` (matches `ActivityRow`'s "low" severity), `#FBBF24` and `#F97316`→both map to `oklch(82.8%_0.189_84.429)` (matches `ActivityRow`'s existing precedent of collapsing medium+high into one amber tone — same file, same established decision, not new).
- Critical: `#EF4444`→`oklch(70.4%_0.191_22.216)`, the dominant error/critical token used everywhere else in V2 (30 occurrences across existing files).
- `#A479E2` (a decorative purple used for local-YOLO-detection indicators, no V2 equivalent exists) → a newly-defined but properly-formed oklch value, `oklch(78%_0.15_300)`, chosen to sit at a similar lightness/chroma magnitude as the rest of the V2 palette.
- `#BBF7D0` (a single-use light green) → reuses the established success-green token, `oklch(79.2%_0.209_151.711)`, for simplicity given its low usage (1 occurrence).

- [ ] **Step 5: Wrap the outer container to match V2's page-shell convention**

`AppShellV2`'s `<main>` (unlike the old `AppShell`) applies no padding of its own — every V2 page wraps its own content in a `max-w-[...] mx-auto px-12 pt-12 pb-20` container. This page's internal layout is a 3-column grid (`grid-cols-1 lg:grid-cols-3`, video feed spanning 2 columns + a side panel spanning 1) wider than the narrow single-column content most other V2 pages show, so use a wider max-width than the usual `1040px`.

Find the page's outer return statement (currently `return (<div className="space-y-4"> ... </div>);`) and wrap it:

```tsx
// change:

  <div className="space-y-4">
    ...
  </div>
);

// to:
return (

    <div className="space-y-4">
      ...
    </div>
  </div>
```

This only touches the single opening/closing wrapper — every other line of the file (already copied and recolored) stays as-is.
